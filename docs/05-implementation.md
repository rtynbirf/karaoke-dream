# Пакет реализации

Практический документ: как устроена работа в репозитории — стек, соглашения, процессы, чек-листы. Если меняешь поведение — меняй этот документ в том же PR.

## 1. Стек и принципы

- **Vanilla ES-модули** (`"type": "module"`), ноль рантайм-зависимостей, ноль сборки.
- **Node ≥ 18** — только для тестов и smoke; сам продукт — браузер.
- **Чистое ядро / грязная оболочка**: логика без DOM/AudioContext (`lyrics`, `scoring`, `songs`, `audio/pitch`) тестируется в Node; всё, что с DOM/WebAudio, — только smoke-импорт и ручной чек-лист.
- **Приватность по построению**: никаких fetch/XHR в рантайме. Если понадобится — только с явным ADR.

## 2. Структура репозитория

```
karaoke-dream/
├── index.html                 # единственная страница (SPA)
├── public/logo.svg            # баннер для README
├── src/
│   ├── css/neon.css           # неон-тема
│   └── js/
│       ├── main.js            # оркестратор (автозапуск только в браузере)
│       ├── util/              # bus, storage, dom
│       ├── lyrics/            # lrc.js (парсер/сериализатор), sync.js
│       ├── scoring/           # judge.js, corridor.js — чистая логика
│       ├── songs/             # demo.js — композитор, единый источник правды
│       ├── audio/             # engine.js, synth.js, pitch.js
│       └── ui/                # screens.js, canvas.js
├── tests/                     # node:test, чистая логика
├── scripts/smoke-import.mjs   # импорт всех модулей в Node
├── docs/                      # 01-концепция … 05-реализация (этот файл)
└── .github/                   # CI, шаблоны, dependabot
```

## 3. Локальная разработка

```bash
npm run dev     # http://localhost:5173 (serve) — микрофон работает на localhost
# альтернатива без npx: python3 -m http.server 5173
npm test        # node --test (21 тест чистой логики)
npm run smoke   # все модули импортируются в Node
```

Требование браузера: Chrome/Edge/Firefox/Safari последних двух версий. Микрофон — только на `localhost` или HTTPS.

## 4. Git-процесс

- Ветвление: `main` защищён; фичи — короткоживущие ветки `feat/…`, фиксы `fix/…`.
- **Conventional Commits**: `feat:`, `fix:`, `docs:`, `refactor:`, `test:`, `chore:`. Пример: `feat(audio): автокалибровка задержки клик-тестом`.
- Версии — SemVer, журнал — `CHANGELOG.md` (Keep a Changelog).
- PR-шаблон обязывает: тесты зелёные, smoke зелёный, нет innerHTML на пользовательском вводе, документы обновлены.

## 5. CI/CD

- GitHub Actions (`ci.yml`): матрица Node 18/20/22 → `node --test` + smoke-импорт. Время прогона — секунды (нет установки зависимостей).
- **GitHub Pages** — деплой статики из `main` (корень репо). Публикация новой версии = merge в `main`.
- Dependabot: еженедельно следит за actions/npm-экосистемой (про запас).

## 7. Definition of Done (для любой фичи)

1. Код в стиле репо (ESM, чистая логика отделена, `.js` в импортах).
2. `npm test` и `npm run smoke` зелёные локально и в CI.
3. Новая чистая логика покрыта тестами; грязная — описана в ручном чек-листе.
4. Документы (`docs/`) и `CHANGELOG.md` отражают изменение.
5. Проверено руками в двух браузерах (минимум Chrome + Firefox/Safari).
6. Сетевых запросов не появилось (проверка вкладкой Network).

## 8. Безопасность и приватность

- Пользовательский ввод (LRC, имена, названия файлов) — только через `textContent`/`createElement`.
- Разрешения: только `microphone`; c отключёнными улучшалками (`echoCancellation/noiseSuppression/autoGainControl: false`) — иначе питч-детектор врёт.
- Отчёт по уязвимостям — приватно через Security Advisory (`SECURITY.md`).

## 9. Как расширять (карта точек роста)

- Новая песня-модуль: добавить файл в `src/js/songs/`, экспортирующий данные формата `DEMO` — синтез, лирика, оценка и коридор заработают сами.
- Новый режим оценки: объект в `judge.js → MODES` + пункт в селекте экрана настройки.
- Новая ось коридора (темп, плотность гид-вокала): политика в `corridor.js`, применение — в `engine.js` (у буферных источников есть и `playbackRate`).
- Стемы/MIDI-эталоны: новый модуль `src/js/audio/stems.js` (ONNX Runtime Web) + ADR; интерфейс `engine.setBuffers` уже готов принять раздельные слои.
