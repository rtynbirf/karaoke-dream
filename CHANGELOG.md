## [0.1.0] — 2026-10-28

### Добавлено
- Прототип «КАРАОКЕ МЕЧТЫ 2.0»: одностраничное браузерное караоке на WebAudio (zero-dependency, без сборки).
- Демо-песня «Неоновый вектор», синтезируемая целиком в браузере (офлайн-рендер: пэд, бас, барабаны, гид-мелодия).
- Гид-вокал с отдельной громкостью; минус-вокал для загруженных треков (вычитание центрального канала).
- Pitch-детектор YIN на микрофонном входе (чистый DSP на Float32, без библиотек).
- Оценка пения в реальном времени: точность / ритм / стабильность, режимы «Дружелюбный» и «Жюри» (0–100).
- «Зелёный коридор» — адаптивная тональность: при просадках сцена транспонируется к певцу (detune), при росте возвращается к оригиналу.
- Лирика: парсер/сериализатор Enhanced LRC (пословные тайминги), автосинхронизация подсветки слов.
- Питч-трейл на canvas: голосовая кривая поверх целевой мелодии, неоновая графика.
- Вечеринка: очередь певцов, лидерборд (localStorage), режим «большой экран».
- Тесты чистой логики (node:test) и smoke-импорт всех модулей; CI на GitHub Actions (Node 18/20/22).
- Документация: концепция, ТЗ, архитектура (ADR), дорожная карта, пакет реализации.
