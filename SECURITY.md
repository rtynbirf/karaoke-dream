# Политика безопасности

## Модель угроз и приватность

KARAOKE DREAM — полностью клиентское приложение. Ключевые следствия:

- **Микрофон**: аудиопоток анализируется в браузере (WebAudio + YIN) и **не покидает устройство**. Нет сети, нет серверов, нет телеметрии.
- **Данные**: имя певца, настройки, очередь и лидерборд хранятся только в `localStorage` браузера.
- **Файлы**: загруженные треки декодируются локально и никуда не отправляются.

## Как сообщить об уязвимости

1. Откройте [Security Advisory](https://github.com/rtynbirf/karaoke-dream/security/advisories/new) (приватно) — предпочтительный путь.
2. Либо заведите issue с пометкой `[security]`, **без** деталей эксплойта, и уточните детали по запросу.

Ожидаемый срок реакции — 7 дней.

## scope (в границах проекта)

- Инъекции через вставляемую лирику (LRC) — парсер должен быть устойчив к произвольному тексту.
- XSS через имена певцов / названия файлов при рендере UI — в UI используется `textContent`/`createElement`, `innerHTML` для пользовательских строк запрещён.
- Разрешения: приложение запрашивает только `microphone`.
